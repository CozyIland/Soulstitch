## Vermutliche Hörfehler der Abschrift

Die Abschrift ist automatisch erstellt. Diese Stellen sind wahrscheinlich falsch erkannt:

- „Fullmetal Agumas Brotherhood“ → Fullmetal Alchemist: Brotherhood
- „Conduits“ ist gemeint bei „Condolence“, „Cognites“, „Cognit-Kreislauf“
- „Malschi“ und „Mulchi“ meinen wohl dieselbe Figur
- „Sehnenenergie“, „Sehnenessenz“ → Seelenenergie, Seelenessenz
- „Schad“ → halb (½)
- „Zäudogott“ → Pseudogott
- „reintrittig“ → vermutlich „vorher“ oder „nacheinander“
- „Gampel“ → Gameplay; „Schreibtal“ → unklar
